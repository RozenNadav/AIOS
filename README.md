# AIOS — AI Operating System

**AIOS** is a cognition-first, future-driven operating system for developers.
It is **not** based on Windows, Unix, Linux, or POSIX.

> **v0.2.1 DevCore** — Cognition Core, Intent Bus, Silicon Lattice (NVIDIA + AMD).

## Quick start

### Developer console (browser)

```bash
cd console
npm install
npm run dev
```

Open http://localhost:5173 and click **Ignite Cog**.

### Intent shell (Rust)

```bash
cargo run -- boot
cargo run -- shell
```

See docs/ for architecture and silicon support.
